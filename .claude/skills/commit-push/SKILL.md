# Commit and Push Workflow

1. Run `git status` to see all changes
2. Group related changes into logical commits with descriptive messages
3. Reference any TODO items or issues being resolved in commit messages
4. Push to the current branch
5. If changes apply to other branches (e.g., 356, 357), cherry-pick or propagate as needed
